# CodeStrome Hackathon 2024 - Registration Website

A modern, responsive hackathon registration website built with HTML, CSS, and JavaScript. Features a classic, professional design that works seamlessly across all devices.

## 🚀 Features

### Design & UI
- **Classic Professional Look**: Clean, modern design with a professional color scheme
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Subtle hover effects and scroll animations
- **Modern Typography**: Uses Inter font family for excellent readability
- **Gradient Accents**: Beautiful blue gradients for buttons and highlights

### Functionality
- **Interactive Navigation**: Smooth scrolling and mobile-friendly hamburger menu
- **Registration Form**: Comprehensive form with validation and submission handling
- **Contact Form**: Easy-to-use contact form for inquiries
- **Form Validation**: Client-side validation with error messages
- **Responsive Grid Layouts**: CSS Grid for flexible, responsive layouts

### Technical Features
- **Mobile-First Design**: Responsive breakpoints for all screen sizes
- **Performance Optimized**: Debounced scroll events and efficient animations
- **Accessibility**: Keyboard navigation and focus management
- **Touch Support**: Mobile gesture support and touch-friendly interactions
- **Cross-Browser Compatible**: Works on all modern browsers

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: 480px - 767px
- **Small Mobile**: Below 480px

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Customize** the content, colors, and branding as needed
4. **Deploy** to your web hosting service

## 🎯 Customization

### Changing Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #3b82f6;
    --accent-color: #10b981;
}
```

### Updating Content
- **Event Details**: Modify the hackathon information in the About section
- **Registration Form**: Add/remove form fields as needed
- **Contact Information**: Update contact details and social media links
- **Branding**: Change the logo, colors, and company name

### Adding Features
- **Countdown Timer**: Uncomment the countdown display code in `script.js`
- **Image Gallery**: Add images to the hero section or create new sections
- **Payment Integration**: Connect the registration form to a payment processor
- **Email Notifications**: Add server-side form processing
